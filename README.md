## Why this project exists

I started building these workflows because running a small digital product business involves a lot of repetitive work.

Orders need to be tracked.

Customers need to be notified.

Information needs to be recorded.

Follow-up needs to happen.

It's easy to keep adding automation until the automation itself becomes another system to maintain.

This project is an attempt to keep things practical.

Automate repetitive work.

Don't automate complexity just because you can.

## What this project does

This repository provides practical automation examples for digital product businesses.

* Digital product delivery
